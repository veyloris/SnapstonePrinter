## Architecture decision

Use a single GitHub Actions build job around the existing Gradle wrapper so local and hosted checks execute the same tasks. Preserve the single-module application and dependency versions except the Step 3 KSP patch. Reject signed release publishing and Trivy for this milestone because they do not establish the requested build baseline or update flow.

Use Renovate as the sole dependency-update bot, with configuration separate from its external installation. Retain manual review and all CI checks on update PRs. Do not set `statusCheckNames` to a shortened list or enable automerge. Prefer native Gradle and GitHub Actions managers over a custom version parser. Follow [Renovate's configuration reference](https://docs.renovatebot.com/configuration-options/) when validating the exact options.
